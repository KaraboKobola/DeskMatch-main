DeskMatch

By turning everyday digital organization tasks into a timed puzzle, DeskMatch aims to combat digital clutter and poor file management habits that plague our daily digital lives. This game makes the often tedious task of organizing files engaging and rewarding, while building real-world skills in systematic thinking, spatial organization, and time management under pressure. The precision and attention to detail required translate directly to improved productivity, reduced digital stress, and better organization in your actual work and personal computer environments.

Controls & Shortcuts

Mouse Controls

  • Click - Select item (clears previous selection)
  • Right-Click - Multi-select item (keeps previous selections)
  • Click on name - Rename item
  • Double-click folder - Open folder
  • Drag & Drop - Move items on grid
  • Drag to trash - Delete item
  • Double-click desktop - Create new item

Keyboard Shortcuts

  • Arrow Keys - Navigate to adjacent items
  • Enter - Select item
  • Shift + Enter - Add newly selected item to selection (multi-select)
  • G - Group selected items into folder
  • G (in folder) - Ungroup selected items
  • R - Rename selected item
  • M - Enter move mode
  • Arrow Keys (in move mode) - Move item
  • Enter (in move mode) - Exit move mode
  • N - Create new item
  • Escape - Cancel action / Exit keyboard navigation
  • ? - Toggle this help panel

Folder Management

  • Select 2+ items → Press G → Creates folder
  • Double-click folder → Click items → Press G → Takes out
  • Gold button appears when items selected
  • Brown button appears for ungrouping

Protected Items

  • Browser, Printer, Settings - Cannot rename, delete, or group
  • All other items are movable and editable

Voice Commands

  • "Select [name]" - Select an item by name (clears previous selection)
  • "Shift select [name]" - Add item to selection (keeps previous selections)
  • "Delete" / "Remove" - Delete selected item
  • "Move up/down/left/right" - Move selected item
  • "Rename to [name]" - Rename selected item
  • "Group" / "Create folder" - Group selected items
  • "Create image/text/zip/video" - Create new item
  • "Deselect" - Clear selection
  • "Help" - Toggle this panel
