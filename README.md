# DeskMatch

Built with HTML, CSS, and JavaScript, DeskMatch is an interactive precision game that challenges players to recreate a randomly selected target desktop layout as accurately as possible. Players see a small reference preview of the target desktop throughout the round and must match it using a variety of actions including dragging and repositioning icons, renaming files, creating folders, grouping elements, and deleting unnecessary items. The game supports multiple input methods: mouse interactions (click, right-click, drag-and-drop), keyboard navigation with arrow keys and shortcuts, and voice commands for hands-free control. This multi-modal approach ensures accessibility and inclusion, allowing players with different abilities and preferences to engage with the game using their preferred interaction method.

Players have 1 minute and 30 seconds to complete the challenge. When time runs out or when the user clicks the "Finish this Round" button, DeskMatch evaluates the player's desktop against the target layout, checking icon positions, names, folder groupings, and item deletions. The evaluation generates a grade out of 100 with a corresponding letter grade (A+, A, B+, etc.), along with a detailed performance report showing which items were correctly placed, incorrectly positioned, incorrectly named, or should have been deleted but weren't.
